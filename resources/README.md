# Open Educational Resources & Project Assets

This directory serves as the repository and index for Open Educational Resources (OER), visual guides, assessment templates, and reference materials developed and curated for the **Material Literacy and Resource Assessment (MLRA)** project.

---

## 📂 Directory Contents & Planned Resources

* **`guides/`**: Step-by-step instructional guides (e.g., *Low-tech Plastic Identification Guide*, *Multimeter Safety & Diagnostic Basics*).
* **`templates/`**: Printable and fillable worksheets for community workshops, teardown triage sheets, and material audit logs.
* **`rubrics/`**: Evaluation rubrics for condition diagnosis, repair viability, and component harvesting.
* **`translations/`**: Translation packages and localization kits for adapting materials into multiple languages.

## 🎯 Key Topics Presented

1. **How Permanent Are Project Outputs?**
   * Addressing the recurring cycle where valuable community knowledge, curricula, and platforms disappear after project grants expire (e.g., Welder app, Critical Making mentoring sessions on YouTube, mAkE MOOC platform outages).
2. **Investing in Platforms That Last:**
   * Combining open-source code, data sovereignty, and community ownership.
   * Documentation via Appropedia and Codeberg; static preservation on Zenodo and the Internet Archive; structured courses on the **Global Innovation Academy (GIA)** running on Open edX.
3. **Collaboratively Advancing Knowledge of Materials:**
   * Introducing the Hans Sauer Stiftung-funded project *Material Literacy and Resource Assessment (MLRA)* building on the Citizen Science *Circular Material Valuer Curriculum (CMVC)*.
4. **Next Steps & Call to Action:**
